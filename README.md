# Academic homepage

A static, responsive homepage for Sheikh Arsalan-ul-Haque. It can be hosted by GitHub Pages without a build step.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Add these files at the repository root and push them to the default branch.
3. In the repository's **Settings → Pages**, choose **Deploy from a branch**, then select the default branch and `/ (root)`.

The CV and full research links currently point to the existing Google Sites pages. They can be replaced when those pages are migrated.
